Penjelasan kode program :<br>
1. dictionary buku = menyimpan data buku (judul, penulis, tahun terbit) dalam bentuk pasangan key dan value
2. print = menampilkan teks, menu dan data ke layar 
3. input = menerima masukkan dari user
4. if = menjalankan perintah sesuai pilihan user
5. elif = mengecek pilihan menu lainnya
6. else = digunakan saat pilihan yang dimasukkan tidak tersedia
7. buku["Penerbit"] = menambahkan penerbit ke data buku
8. buku["penulis"] = mengganti nama penulis ke data baru
9. del buku["penerbit"] = menghapus data penerbit
10. break = menghentikan program saat user memilih keluar
